## Course Introduction
This repository documents my coursework and hands-on exploration for **CPELX230-330 (Term 2, 2026–2027)** at **National University – College of Engineering**, focusing on **Agentic Software Engineering and Responsible AI**.

## Personal Learning Goals
- Understand how to design reliable agentic workflows with clear tool boundaries, state handling, and testing.
- Strengthen practical software engineering habits using Git branching, clean commits, and iterative Scrum-style milestones.
- Apply risk management and responsible AI principles—such as safety, privacy, transparency, and human oversight—when building autonomous systems.

## Reflection from Part A
Moving from deterministic code to agentic systems shifts the engineer's role toward shaping goals, constraints, tool access, and verification loops. While autonomy makes software more adaptable to messy real-world tasks, it also amplifies the need for disciplined version control, incremental Agile testing, clear risk mitigation, and meaningful human oversight.
